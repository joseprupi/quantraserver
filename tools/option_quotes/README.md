# Option quote sheets from vendor files

`cboe_eod_to_quote_sheet.py` turns a Cboe DataShop **Option EOD Summary**
CSV (one row per option series and day) into the `OptionQuoteSheet` that
`POST /calibrate-implied-forwards` (and, next, the vol-surface calibration)
reads: one line per expiration x strike with the call and put bid/ask side
by side, plus the spot as a `QuoteSpec` and the quote date.

Vendor files are licensed: they are never committed to this repository, and
neither is anything derived from them. The repository's only quote sheet is
the synthetic one under `examples/data/implied_forwards/`, generated by
`tests/tools/make_synthetic_quote_sheet.py`.

Python 3 standard library only; no server or build needed.

## Usage

```bash
# End-of-day snapshot (default), spot from the underlying bid/ask mid
python3 tools/option_quotes/cboe_eod_to_quote_sheet.py NDX_2026-09-30.csv \
    --root NDX --out ndx_2026-09-30_sheet.json

# 15:45 snapshot, spot from active_underlying_price_1545
python3 tools/option_quotes/cboe_eod_to_quote_sheet.py NDX_2026-09-30.csv \
    --root NDX --snapshot 1545 --out ndx_2026-09-30_1545_sheet.json

# Override the spot, name the underlying as it will be in pricing.equity
python3 tools/option_quotes/cboe_eod_to_quote_sheet.py RUT_2026-10-19.csv \
    --spot 2345.67 --underlying-id RUT --out rut_sheet.json
```

The output is

```json
{
  "as_of_date": "2026-09-30",
  "spot": {"id": "NDX_SPOT", "kind": "Price", "value": 24123.45, "quote_type": "Curve"},
  "sheet": {"id": "NDX_2026-09-30_eod", "underlying_id": "NDX", "option_style": "European",
            "quotes": [{"expiry": "2026-10-16", "strike": 23000.0,
                        "call_bid": ..., "call_ask": ..., "put_bid": ..., "put_ask": ...,
                        "call_volume": ..., "put_volume": ...,
                        "call_open_interest": ..., "put_open_interest": ...}, ...]},
  "source": {"snapshot": "eod", "rows_read": 1234, "columns": {...}, "spot_from": "...", ...}
}
```

`source` says exactly which columns were used and where the spot came from;
drop it before posting (the gateway rejects unknown fields). The request is
assembled by the caller:

```json
{
  "pricing": {
    "as_of_date": "<as_of_date>",
    "quotes": [ <spot> ],
    "rates": {"curves": [ <your discounting curve>, <a flat 0 % placeholder dividend curve> ]},
    "equity": {"equity_underlyings": [{"id": "NDX", "currency": "USD",
               "spot_quote_id": "NDX_SPOT", "dividend_yield_curve_id": "<placeholder id>"}]}
  },
  "sheet": <sheet>,
  "discounting_curve": "<your discounting curve id>",
  "filter": {"max_relative_spread": 0.05, "min_quotes_per_expiry": 4, "moneyness_window": 0.25},
  "dividend_curve_id": "NDX_DIV_IMPLIED"
}
```

The discounting curve is yours (an OIS bootstrap or zero points); the tool
does not invent one. `EquityUnderlyingSpec.dividend_yield_curve_id` must
resolve because the shared market-data registry requires it; the endpoint
does not read it, so a flat 0 % `InterpolatedZero` curve is the placeholder.

## Columns

The Cboe product's field list is matched after lower-casing and replacing
spaces and dashes with underscores; the accepted variants are in
`COLUMN_CANDIDATES` at the top of the script. Required: `expiration`,
`strike`, `option_type` (C/P, call/put) and the bid/ask pair of the chosen
snapshot (`bid_eod`/`ask_eod`, or `bid_1545`/`ask_1545`; a plain
`bid`/`ask` is read as EOD). Used when present: `quote_date`, `root`,
`underlying_symbol`, `trade_volume`, `open_interest`, `underlying_bid_eod`
/ `underlying_ask_eod`, `active_underlying_price_1545`,
`underlying_bid_1545` / `underlying_ask_1545`. Greeks and implied
volatilities are ignored (the engine computes its own).

Rules the tool enforces rather than guesses: several roots in one file
(NDX monthlies next to NDXP weeklies) need `--root`; several quote dates
need `--quote-date`; no usable underlying price column needs `--spot`.
Zero bids are kept as they are (a `0 / ask` line has a relative spread of
2, so the engine drops it under any sensible `max_relative_spread`); a
series quoted on one side only becomes a line with the other side absent,
which the engine reports as "missing call or put side".

`option_style` is written as `European` (index options). A single-stock
sheet is American: set it so, and the engine will refuse it with 400 —
put-call parity does not hold for American options, so implied forwards
cannot be read from them with this method.

Unit test: `tests/contract/cboe_eod_to_quote_sheet_test.py` (pure Python,
hand-written CSV in the product's column format).
