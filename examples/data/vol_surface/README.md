# Volatility surface from option quotes — examples

`POST /calibrate-vol-surface` requests. One synthetic quote sheet, written
as two requests (one per method). **Nothing here is market data**: the sheet
is generated by `tests/tools/make_synthetic_quote_sheet.py` from a stated
surface, and a test asserts each file equals the generator's output.
Licensed vendor files (Cboe DataShop and the like) are never committed;
`tools/option_quotes/cboe_eod_to_quote_sheet.py` turns one into a sheet of
this shape.

| File | Content |
|---|---|
| `synthetic_svi_sheet_2026-09-30_andreasen_huge.json` | The SVI sheet, `method: AndreasenHuge` (default grid, forwards fitted internally). |
| `synthetic_svi_sheet_2026-09-30_svi.json` | The same sheet, `method: SviPerExpiry` (butterfly and calendar enforcement on). |

Both are produced by

```bash
python3 tests/tools/make_synthetic_quote_sheet.py --preset svi --endpoint vol-surface \
  --method AndreasenHuge --out examples/data/vol_surface/synthetic_svi_sheet_2026-09-30_andreasen_huge.json
python3 tests/tools/make_synthetic_quote_sheet.py --preset svi --endpoint vol-surface \
  --method SviPerExpiry --out examples/data/vol_surface/synthetic_svi_sheet_2026-09-30_svi.json
```

## What was put in

`SYNTHETIC_SVI_NDX_LIKE` in the generator: the NDX-like market of
`examples/data/implied_forwards/` (spot 24000, as-of 2026-09-30, the
`USD_OIS_SYN` zero curve, a dividend yield per expiry, 8 third-Friday
expiries, 25 strikes from 70 % to 130 % of spot, exact Black mids with a
1 % bid/ask) with the smile replaced by an SSVI power-law surface
(Gatheral-Jacquier 2014):

```
w(k, θ) = θ/2 · (1 + ρ φ k + sqrt((φ k + ρ)² + 1 − ρ²)),  θ = σ_ATM² T,  φ = 1 / sqrt(θ)
```

with `ρ = −0.7` and ATM vols 23.0, 22.5, 22.0, 21.5, 21.0, 21.0, 21.0,
21.0 % at the eight expiries. Per expiry this is the raw SVI slice
`a = θ(1 − ρ²)/2`, `b = θφ/2`, `σ = sqrt(1 − ρ²)/φ`, `m = −ρ/φ`; the ATM
vol skew is `ρ / (4 √T)` (steep at 16 days, flattening with maturity), and
the surface is free of calendar arbitrage (θ increasing in T) and of
butterfly arbitrage (`θφ(1 + |ρ|) < 4`, `θφ²(1 + |ρ|) ≤ 4`) by
construction. `python3 tests/tools/make_synthetic_quote_sheet.py --preset
svi --truth` prints the forward, discount factor, yield and SVI parameters
per expiry.

## What comes out

Per expiry: the forward and implied discount factor used, `quotes_used`
(the deep short-dated wings whose out-of-the-money mid is below 1e-5 of the
spot are dropped as uninformative, with that reason), `rmse_vol` /
`max_abs_error_vol` against the market implied vols, for SVI the fitted
`a, b, sigma, rho, m` (the generating ones to ~1e-6) and the butterfly /
calendar findings; `vol_surface_spec`, the `BlackVolSpec` on the default
41 x 8 grid (strikes 50 % to 150 % of spot every 2.5 %, the eight sheet
expiries as calendar-day periods); and `vanilla_repricing`, every used quote
repriced on that surface — all inside their bid/ask under both methods on
this sheet. See "Volatility surface from option quotes" in
`docs/http-api.md` for the method and every field.

## The two-step flow

1. `POST /calibrate-implied-forwards` with the sheet (the request in
   `examples/data/implied_forwards/` has the same shape) → forwards, implied
   discount factors and the `dividend_curve_spec`.
2. `POST /calibrate-vol-surface` with the sheet and, optionally, the first
   response's `expiries` array as `forwards` (without it the fit is rerun
   here, same result) → `vol_surface_spec`.
3. Paste `dividend_curve_spec` into `pricing.rates.curves` (and set the
   underlying's `dividend_yield_curve_id`) and `vol_surface_spec` into
   `pricing.volatility.vol_surfaces`; reference the vol id from an equity
   option's `volatility` or a structured note's `underlyings[].volatility_id`
   with `monte_carlo.steps_per_year` set (Dupire local vol).

`examples/data/structured_note/scotia_autocallable_trigger_ndx_rty_us06419jme72_with_synthetic_surface.json`
is step 3 applied to the Scotia note: its NDX and RTY vols are surfaces
calibrated with the SVI method from the `svi` and `svi_rty` presets
re-struck at the note's own spot levels (`--spot 30408.5 --underlying-id
NDX`, `--spot 2796.864 --underlying-id RTY`). Those surfaces are synthetic:
the file shows the shape of a surface-priced note, not a market value.

## Running

```bash
curl -X POST http://localhost:8080/calibrate-vol-surface \
  -H "Content-Type: application/json" \
  -d @examples/data/vol_surface/synthetic_svi_sheet_2026-09-30_svi.json
```
