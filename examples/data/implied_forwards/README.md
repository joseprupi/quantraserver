# Implied forwards and dividends from option quotes — examples

`POST /calibrate-implied-forwards` requests. One file, **entirely
synthetic**: no quote here was ever traded. Licensed vendor files (Cboe
DataShop and the like) are never committed, and neither is anything derived
from them; the converter for them is `tools/option_quotes/`.

| File | Content |
|---|---|
| `synthetic_ndx_like_2026-09-30.json` | NDX-like index, 8 third-Friday expiries (2026-10-16 … 2027-12-17), 25 strikes from 70 % to 130 % of spot, exact Black mids quoted with a 1 % bid/ask, open interest and volume decaying away from the money. Generated by `tests/tools/make_synthetic_quote_sheet.py`; a test asserts the file equals the generator's output. |

## What was put in (so the output can be checked)

All numbers are round and stated, in `SYNTHETIC_NDX_LIKE` at the top of the
generator:

- spot `S = 24000` (quote `NDX_SYN_SPOT`), currency USD, as-of 2026-09-30;
- discounting curve `USD_OIS_SYN`: continuous zero rates 4.00 % (as-of),
  3.80 % (1Y), 3.70 % (3Y), 4.00 % (10Y), linear in Act/365F time (the
  engine's `InterpolatedZero` + `Linear`);
- continuous dividend yield per expiry: 0.80 %, 0.85 %, 0.95 %, 1.00 %,
  1.05 %, 1.10 %, 1.15 %, 1.20 %;
- Black smile in log-moneyness `k = ln(K / F)`: `σ = 0.20 − 0.40 k + 0.80 k²`
  clipped to [5 %, 100 %] (stage 2, the vol-surface calibration, recovers
  this);
- every call and put priced with the Black formula on
  `F = S · e^{(r − q) T}`, `DF = e^{−r T}`; `bid / ask = mid · (1 ∓ 0.5 %)`, so
  the mid is exact and parity holds exactly;
- open interest `5000 · e^{−4 |k|}` (volume half of it).

`python3 tests/tools/make_synthetic_quote_sheet.py --truth` prints the
generating forward, discount factor and yield per expiry. `--noise 0.02
--seed 7` perturbs the mids multiplicatively (the contract test runs that
case and checks the recovery is within the noise); `--spread` changes the
bid/ask width.

Because the schema requires one, the `EquityUnderlyingSpec` references a
flat 0 % placeholder dividend curve (`NDX_SYN_DIV_PLACEHOLDER`); the endpoint
does not read it.

## What comes out

Per expiry: `forward`, `implied_discount_factor` (−slope), the curve's
`curve_discount_factor`, `implied_funding_bp` (0 here: the quotes were
generated on the same curve), `implied_dividend_yield` (the yields above,
to 1e-10), `fit_residual_rmse` / `max_abs_residual` (~1e-12 on exact
mids), `quotes_used` (21 of 25: the 70 %, 72.5 %, 127.5 % and 130 %
strikes fall outside the ±25 % moneyness window and are listed under
`dropped` with the window bounds) — see "Implied forwards and dividends
from option quotes" in `docs/http-api.md` for the method and every field.

`dividend_curve_spec` is the curve to paste into a pricing request:

```json
"rates": {"curves": [ <USD_OIS_SYN>, <dividend_curve_spec as returned> ]},
"equity": {"equity_underlyings": [{"id": "NDX_SYN", "currency": "USD",
           "spot_quote_id": "NDX_SYN_SPOT", "dividend_yield_curve_id": "NDX_SYN_DIV_IMPLIED"}]}
```

With that, a European call/put pair at any strike priced by
`/price-equity-option` on `USD_OIS_SYN` satisfies
`(C − P) / DF_curve + K = F` at the fitted expiries (the contract test
`tests/contract/implied_forwards_test.py` does exactly this).

## Running

```bash
curl -X POST http://localhost:8080/calibrate-implied-forwards \
  -H "Content-Type: application/json" \
  -d @examples/data/implied_forwards/synthetic_ndx_like_2026-09-30.json
```
